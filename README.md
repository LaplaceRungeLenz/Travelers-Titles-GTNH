# Traveler's Titles GTNH

面向 Minecraft 1.7.10 Forge / GT New Horizons 的客户端模组，在进入维度、行星或群系时显示淡入淡出的地点标题，灵感来自 Traveler’s Titles。

- 内置 54 款英文像素标题，覆盖原版、常见模组维度与太空天体；群系名称随游戏语言显示，并使用主题配色。
- 支持游戏内调整字号、颜色、位置、显示行为和音量，提供保存、恢复默认和预览。
- 支持通过资源包与 JSON 自定义文字、图片、样式、声音和动画。

将 `travelerstitlesgtnh-0.1.0.jar` 放入客户端 `mods` 文件夹，服务器无需安装。

配置入口：**Mod 列表 → Traveler's Titles GTNH → Config**，进入世界后同样可用。修改外观时，先开启对应分类的“启用外观覆盖”，再点击“完成”保存生效。
